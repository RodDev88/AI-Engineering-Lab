# 1. ¿Qué es AI Engineering Lab?

AI Engineering Lab es un laboratorio de aprendizaje diseñado para estudiar AI Engineering mediante la ingeniería inversa de proyectos reales.

Cada proyecto del laboratorio parte de un sistema existente, analiza sus decisiones de diseño y arquitectura, y lo reconstruye paso a paso con fines educativos.

El objetivo no es copiar software existente, sino comprender cómo fue concebido y por qué sus creadores tomaron determinadas decisiones técnicas.

# 2. Misión

Aprender AI Engineering mediante la ingeniería inversa de proyectos reales, transformando productos existentes en experiencias estructuradas de aprendizaje que permitan comprender su arquitectura, implementación y diseño.

# 3. Visión

Construir una biblioteca de proyectos reconstruidos que documente patrones, decisiones arquitectónicas y aprendizajes reutilizables provenientes de sistemas reales de AI Engineering.

Cada nuevo proyecto debe enriquecer el laboratorio y servir como referencia para los siguientes.

# 4. Alcance

El laboratorio se centra exclusivamente en proyectos reales.

Cada proyecto busca responder preguntas como:

- ¿Qué problema resuelve?
- ¿Cómo fue diseñado?
- ¿Qué arquitectura utiliza?
- ¿Qué tecnologías emplea?
- ¿Qué decisiones de ingeniería explican su funcionamiento?
- ¿Cómo podría reconstruirse desde cero?

El laboratorio documenta el proceso de aprendizaje derivado de esas preguntas.

# 5. Lo que NO es este laboratorio

AI Engineering Lab no pretende reemplazar cursos, bootcamps ni programas completos de formación.

No organiza el aprendizaje general de:

- Python
- Matemáticas
- Machine Learning
- Deep Learning
- Git
- Linux
- Redes
- Bases de datos
- Backend
- Frontend

Estos conocimientos viven fuera del laboratorio.

Cuando un proyecto requiere alguno de ellos, únicamente se estudia la parte necesaria para comprender dicho proyecto.

El proyecto guía el aprendizaje, no al revés.

# 6. Filosofía de aprendizaje

El laboratorio se basa en una idea simple:

**Los proyectos reales constituyen el currículo.**

La teoría aparece únicamente cuando resulta necesaria para comprender una decisión tomada dentro de un proyecto.

El conocimiento siempre se incorpora desde un contexto práctico.

La comprensión tiene prioridad sobre la implementación.

Comprender por qué una solución existe es más importante que reproducirla.

# 7. Principios del laboratorio

## 1. Los proyectos reales son el currículo.

El aprendizaje comienza con sistemas existentes.

---

## 2. La ingeniería inversa es el método principal.

Cada proyecto se estudia descomponiendo su arquitectura y reconstruyéndola progresivamente.

---

## 3. La teoría aparece cuando el proyecto la necesita.

No existen módulos teóricos independientes.

Todo conocimiento tiene un contexto.

---

## 4. Comprender decisiones supera copiar implementaciones.

El objetivo es entender el razonamiento detrás de cada componente.

---

## 5. Cada proyecto deja conocimiento reutilizable.

Todo proyecto debe producir patrones, notas y documentación que puedan utilizarse posteriormente.

---

## 6. La arquitectura tiene prioridad sobre el código.

El código representa una implementación.

La arquitectura explica el sistema.

El laboratorio privilegia comprender primero la arquitectura.

---

## 7. El laboratorio evoluciona proyecto a proyecto.

No existe un plan cerrado.

Cada nuevo proyecto amplía la biblioteca de patrones y conocimientos.

---

# 8. Qué constituye un proyecto

Todo proyecto del laboratorio corresponde a un caso de estudio independiente.

Cada uno parte de un producto real y recorre, de manera estructurada:

1. Comprensión del problema.
2. Ingeniería inversa.
3. Arquitectura.
4. Tecnologías utilizadas.
5. Construcción guiada.
6. Comparación con el sistema original.
7. Reflexión sobre las decisiones de diseño.

Todos los proyectos utilizan una metodología común definida en **LAB-METHODOLOGY.md**.

# 9. Resultados esperados

Cada proyecto debe generar, como mínimo:

- Una reconstrucción funcional.
- Diagramas de arquitectura.
- Registro de decisiones.
- Patrones identificados.
- Glosario de conceptos.
- Resumen ejecutivo.
- Reflexión final.

El laboratorio crece mediante la acumulación de estos activos de conocimiento.
