# 1. Sobre el laboratorio

AI Engineering Lab es un laboratorio personal de aprendizaje enfocado en comprender cómo se diseñan y construyen sistemas reales de inteligencia artificial.

El laboratorio utiliza proyectos existentes como casos de estudio y los transforma en experiencias estructuradas de aprendizaje mediante ingeniería inversa.

El objetivo no es copiar productos existentes.

El objetivo es comprender las decisiones de arquitectura, ingeniería y diseño que los hacen posibles.

---

# 2. Misión

Desarrollar criterio de AI Engineering estudiando sistemas reales, reconstruyéndolos paso a paso y extrayendo patrones reutilizables.

---

# 3. Filosofía

El laboratorio se basa en una premisa:

> Los proyectos reales son el currículo.

La teoría aparece cuando un proyecto la necesita.

Cada sistema estudiado funciona como una oportunidad para comprender:

- arquitectura,
- herramientas,
- patrones,
- decisiones técnicas,
- trade-offs.

---

# 4. Cómo funciona

Cada proyecto atraviesa un proceso común:

```
Proyecto real

      ↓

Investigación

      ↓

Ingeniería inversa

      ↓

Mapa arquitectónico

      ↓

Reconstrucción

      ↓

Experimentación

      ↓

Documentación del aprendizaje
```

---

# 5. Ciclo de un proyecto

Cada proyecto utiliza tres capas de análisis:

## Producto

¿Qué problema resuelve?

---

## Sistema

¿Cómo funciona?

---

## Ingeniería

¿Por qué fue construido así?

---

El objetivo final no es solamente producir código.

Es construir comprensión.
